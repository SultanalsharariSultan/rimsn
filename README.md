# RIMSN — Digital Marketplace

واجهة أمامية ثابتة لمتجر عالمي للمنتجات الرقمية، مبنية بتقنيات الويب الأساسية لتكون سهلة الدمج لاحقاً مع قاعدة بيانات، نظام مصادقة، ودفع إلكتروني.

## المميزات

- تصميم Glassmorphism داكن بطابع مستقبلي مع تموجات وأجسام سائلة متحركة بـ CSS.
- واجهة عربية RTL مع هوية عالمية، تصميم متجاوب للهاتف وسطح المكتب.
- شريط تنقل، Hero، إحصاءات، تصفية المنتجات حسب التصنيف، بطاقات منتجات، وسلة أولية.
- بنية بدون إطار عمل أو اعتماديات تشغيلية، مناسبة للنشر على GitHub Pages أو Vercel أو أي CDN.
- دعم `prefers-reduced-motion` وتجارب hover/focus قابلة للوصول.

## التشغيل محلياً

```bash
python3 -m http.server 4173
```

ثم افتح `http://localhost:4173`.

## نقاط الدمج المستقبلية

1. استبدال بيانات المنتجات الثابتة بطلبات API أو طبقة GraphQL.
2. ربط زر الشراء بسلة حقيقية وحالة مستخدم.
3. إضافة بوابة الدفع، رفع ملفات المبدعين، ونظام التقييمات.
4. إضافة ترجمة كاملة عبر i18n للغة الإنجليزية والعربية.

## هيكل المشروع

```text
index.html   # هيكل الصفحة ومحتوى المتجر
styles.css   # نظام التصميم، الحركة، والاستجابة
app.js       # التصفية، السلة، ورسائل الحالة
```
