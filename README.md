# RIMSN — Digital Marketplace

متجر عربي RTL مستقبلي للمنتجات الرقمية، مبني بتقنيات الويب الأساسية وبهوية Glassmorphism قابلة للنشر على GitHub Pages أو Vercel.

## ما تم إنجازه

- تجربة واجهة عالمية متجاوبة مع دعم `prefers-reduced-motion`.
- منتجات مع تصفية حسب التصنيف، بحث فوري، وسلة شراء محفوظة محلياً.
- تعديل الكميات وحذف المنتجات وحساب الإجمالي داخل سلة جانبية أنيقة.
- رحلة Checkout تجريبية جاهزة للربط مع مزود دفع.
- إنشاء حساب وتسجيل دخول واستعادة كلمة مرور في وضع المعاينة.
- جلسة مستخدم محلية وإمكانية إعادة فتح الموقع مع بقاء السلة.

## التشغيل

```bash
python3 -m http.server 4173
```

ثم افتح `http://localhost:4173`.

## قبل الإطلاق الحقيقي

الواجهة تعمل مباشرة دون مفاتيح سرية، لكن `localStorage` **ليس بديلاً عن Backend**. للإطلاق التجاري:

1. اربط Supabase Auth أو Firebase Auth بدلاً من التخزين المحلي.
2. خزّن المنتجات والطلبات في قاعدة بيانات مع سياسات صلاحيات Row Level Security.
3. اربط Stripe أو Moyasar من خلال خادم/Edge Function، ولا تضع مفاتيح سرية في المتصفح.
4. أضف تخزيناً خاصاً للملفات الرقمية وروابط تنزيل موقعة ومحددة الصلاحية.
5. فعّل البريد الإلكتروني، إعادة تعيين كلمة المرور، التحقق من الحساب، ومكافحة إساءة الاستخدام.
6. أضف صفحات قانونية: الخصوصية، الشروط، وسياسة الاسترداد قبل استقبال المدفوعات.

## الملفات

- `index.html` — الهيكل والمنتجات ونموذج الحساب.
- `styles.css` — نظام التصميم والحركة والاستجابة.
- `app.js` — الفلاتر والبحث والسلة وCheckout والمصادقة التجريبية.

> لم أضع مفاتيح Supabase أو الدفع داخل المستودع حفاظاً على أمان مشروعك. بعد ربط الخدمات ستصبح الرحلات الحالية نقطة الانطلاق للنسخة التجارية.
