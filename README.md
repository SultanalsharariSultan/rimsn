# RIMSN — Digital Marketplace

متجر رقمي عربي RTL بتصميم مستقبلي وتجربة قابلة للنشر.

## المميزات الحالية

- واجهة Glassmorphism متجاوبة مع هوية بصرية أصلية.
- عرض المنتجات، التصنيف، البحث الفوري، صفحة تفاصيل المنتج، والمفضلة.
- سلة شراء جانبية مع حفظ المنتجات والكميات والإجمالي في المتصفح.
- إنشاء حساب وتسجيل دخول واحتفاظ بحالة الواجهة.
- تنقل متجاوب للهاتف وتجربة وصول أساسية ودعم تقليل الحركة.
- بنية واجهة جاهزة لاستبدال طبقة البيانات والدفع لاحقاً.

## التشغيل

```bash
python3 -m http.server 4173
```

افتح `http://localhost:4173`.

## ربط الإنتاج لاحقاً

هذه النسخة تبني **الموقع وتجربة المتجر كاملة**، لكنها لا تدّعي أن المصادقة المحلية أو السلة المحلية آمنة للإنتاج. قبل استقبال مستخدمين أو أموال:

- استبدل حسابات `localStorage` بـ Supabase Auth أو Firebase Auth.
- انقل المنتجات والطلبات إلى قاعدة بيانات مع صلاحيات RLS.
- استخدم Stripe أو Moyasar عبر خادم/Edge Function وWebhooks.
- خزّن الملفات الرقمية في Storage خاص مع روابط تنزيل موقعة.
- لا تضع مفاتيح الخدمة أو الدفع في JavaScript أو المستودع العام.

إضافة بوابة الدفع مستقبلاً لن تتطلب إعادة تصميم الواجهة؛ زر إتمام الطلب موجود كنقطة تكامل واضحة.
