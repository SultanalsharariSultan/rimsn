# RIMSN — Digital Marketplace

واجهة عربية RTL مستقبلية لسوق عالمي للمنتجات الرقمية، مبنية بتقنيات الويب الأساسية بدون إطار عمل.

## ما تم إنجازه

- تجربة Glassmorphism متجاوبة مع هوية بصرية داكنة وحركات خفيفة تراعي `prefers-reduced-motion`.
- صفحة منتجات مع تصفية حسب التصنيف، سلة شراء أولية، ومكوّنات تفاعلية.
- نافذة مصقولة لإنشاء الحساب وتسجيل الدخول والتحقق من البيانات.
- جلسة مستخدم محلية للمعاينة، ورسالة استعادة كلمة المرور.
- بنية Auth قابلة للربط بمزوّد حقيقي مثل Supabase دون إعادة بناء الواجهة.

## التشغيل

```bash
python3 -m http.server 4173
```

ثم افتح `http://localhost:4173`.

## تفعيل المصادقة الحقيقية

النسخة الحالية تعمل فوراً كـ **وضع معاينة** باستخدام `localStorage` حتى يمكن اختبار التصميم بلا إعدادات. لا تستخدم هذا الوضع في الإنتاج لأنه ليس نظام مصادقة آمناً.

لجعل المصادقة حقيقية:

1. أنشئ مشروعاً في Supabase وفعّل Email Auth وميزة استعادة كلمة المرور.
2. أضف مكتبة Supabase وطبقة API في `app.js` باستخدام `signUp`, `signInWithPassword`, و`resetPasswordForEmail`.
3. ضع `supabaseUrl` و`supabaseAnonKey` في إعدادات نشر آمنة (ولا تضع service-role key في الواجهة).
4. أضف رابط إعادة التوجيه إلى قائمة Redirect URLs في Supabase.

هذه الخطوة تحتاج بيانات مشروعك السرية، لذلك لم أضع مفاتيح وهمية داخل المستودع.

## الملفات

- `index.html` — الهيكل، المنتجات، ونموذج المصادقة.
- `styles.css` — نظام التصميم الزجاجي المتجاوب.
- `app.js` — الفلاتر، السلة، المصادقة التجريبية، وإدارة الجلسة.
